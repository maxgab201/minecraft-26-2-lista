# Minecraft 26.2 — Chaos Cubed — Block Checklist

Lista interactiva completa de todos los bloques y variantes de Minecraft 26.2 (Chaos Cubed).

## Características

- ✅ **1,000+ bloques** organizados en 10 categorías
- 🌐 **Bilingüe** — Español e Inglés
- 💾 **Persistencia** — localStorage + Supabase opcional
- 🔍 **Búsqueda** en tiempo real (bilingüe)
- 🖨 **Imprimible** con CSS optimizado
- 📱 **Responsive** — funciona en móvil y desktop

## Uso

Abrí `index.html` en cualquier navegador. No requiere servidor.

## Stack

- HTML + CSS + Vanilla JS
- Supabase (opcional, para sync entre dispositivos)
- Google Fonts (Press Start 2P, Inter)
